Popup notifications

Anything that can POST JSON shows a popup over the running app; buttons POST back to a webhook.

Listener
Keep it on the LAN; never expose it to the internet.
If set, requests need ?token=… or the X-Popup-Token header.
Remote
If the remote does not reach the popup on your firmware, choose evdev. Choose grab to stop the app behind the popup from also seeing the keys.
Raw evdev code, or 0 for off. On Vetro's forwarded remote Home is often 63.
Callback
Every button press and every dismissal is POSTed here as JSON. Any HTTP endpoint will do; it is not Home Assistant-specific.
Defaults
Test
The solid overlay paints the whole screen for a few seconds. If it does not appear, the TV is not letting the popup window draw on top, and that is the thing to fix.
Diagnostics

Read from the TV: the Shard's state, the job it last handled, and both logs (the notifier's is the useful one).
